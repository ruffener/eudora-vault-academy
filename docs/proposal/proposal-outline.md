# Eudora Vault Academy Website — Proposal Outline

## Opportunity

Eudora Vault Academy has a clear athletic niche and active social presence, but needs a professional website to establish credibility, answer parent/athlete questions, and convert interest into contacts or registrations.

## Recommended approach

Launch a simple, polished, mobile-first website first. Avoid a complicated backend in phase 1. Build the site so it can later grow into registration, booking, payments, event pages, and athlete resources.

## Phase 1 — Starter Launch Site

Includes:

- Mobile-friendly homepage
- Training/coaching overview
- Facility/location information
- Coach credibility section
- Contact CTA
- Instagram link
- Basic SEO titles/descriptions
- Local development and GitHub repository setup

## Optional Phase 1 additions

- Separate Coaches page
- FAQ section
- Google Map embed
- Contact form
- Registration button linked to a Google Form
- Launch checklist and maintenance notes

## Future Growth Features

- Online session booking
- Athlete intake form
- Waiver form workflow
- Private lesson request form
- Event/camp calendar
- Photo/video gallery
- Testimonials
- Online payment/deposit links
- Beginner training resources
- Meet/event landing pages

## Assumptions

- Client provides approved logo, photos, coach information, training options, and safety/waiver language.
- Phase 1 does not include a custom CMS, custom database, or online payment system unless separately approved.
- Real athlete photos/testimonials are used only with client approval.
